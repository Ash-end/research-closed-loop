# Validation scope / 验证范围

## English

The local Chinese design underwent six synthetic forward-use scenarios and three follow-up scenarios during development on 2026-10-05. Topics included denominator errors, confounded ablations, test-driven selection/data overlap, starting without data, limited-resource portfolios, and mediator uncertainty. Observed weaknesses led to narrower changes in topic-only startup, supplied-count calculation, runtime estimation, and uncertainty interpretation.

The public English version is a translation and packaging of that design, not a separately benchmarked scientific agent. Structural checks cover the two seven-skill trees, required metadata, relative links, referenced assets, accidental sensitive strings, and language parity of file structure. Installer unit tests cover copy behavior, dry-run behavior, existing-entry preservation, language selection, and unsafe source/destination handling.

These checks do not establish scientific novelty, causal validity, calibrated uncertainty for a real project, publication prospects, or model-independent performance. They do not assert a quantified token saving or success rate. The example scenarios are human-readable behavioral probes, not assertions that a phrase-match test proves reasoning quality.

No private evaluation transcripts, local installation logs, project datasets, credentials, or computer-specific paths are included. No training, paid API invocation, or real scientific study is part of repository validation.

## 中文

本地中文初始设计于 2026-10-05 做过六个模拟试用和三个复测，涉及分母、消融混杂、选模污染/数据重叠、无数据启动、有限资源多线和中介不确定性。实际发现的不足促成了主题启动、给定计数计算、估时与区间解释的窄范围修订。

公开英文版是该设计的翻译和打包，不是另行评测过的科研代理。结构检查覆盖两套七技能目录、元数据、相对链接、模板、意外敏感字符串与语言文件结构对应；安装脚本单元测试覆盖复制、预览、已有入口保护、语言选择和不安全来源/目标处理。

这些检查不能验证真实项目的创新、因果关系、统计校准、录用前景或所有模型的表现，也不提供 token 节省或成功率。示例是供实际试用的判断探针，不是靠匹配句子证明推理可靠。

公开包不包含私人评测原文、本地安装日志、项目数据、凭据或个人电脑路径；验证不包含训练、付费 API 或真实科研研究。
